# 后台管理系统网络隔离与登录限流

将后台管理系统（`/admin*`）与公开 API 做**网络层隔离**：拆分独立 Gin 引擎与监听地址，
并对后台登录施加来源 IP 限流。后台从「同端口、仅凭应用层鉴权」升级为「独立端口、
默认仅本机可达 + 登录限流兜底」。

## 现状

ADR-0009 引入后台管理系统后，`/admin*` 与公开 API 注册在**同一个 Gin 引擎、同一个端口**
（`0.0.0.0:9090`）。虽有独立 JWT 鉴权（`admin.jwt_secret`），但：

* `POST /admin/api/login` 与 `/admin` 前端页面公网可达，可被暴力尝试；
* 登录接口**无任何限流**——攻击者可无限次试密码；
* CORS 为 `Access-Control-Allow-Origin: *`，任意来源浏览器可发起跨域请求。

鉴权隔离 ≠ 网络隔离。后台一旦被攻破，用户隐私数据（账号/评论/日志）全量泄露。

## 决策

### 1. 独立引擎 + 独立监听地址（网络层隔离）

* 公开 API 保持监听 `0.0.0.0:<server.port>`（默认 9090）；
* 后台单独一个 Gin 引擎，监听 `127.0.0.1:<admin.listen_port>`（默认 9091），
  由 `admin.listen_addr` / `admin.listen_port` 配置。默认仅回环，公网物理上无法连接；
* 需局域网访问时，把 `admin.listen_addr` 改为内网 IP（如 `192.168.1.10`）；
  远程管理**推荐走 SSH 隧道 / VPN**，不直接开放后台端口。

### 2. 后台登录限流（应用层兜底）

* 复用 `pkg/ratelimit`（内存固定窗口），按来源 IP 限 **5 次失败尝试**/分钟；
* **只计失败**：请求到达先 `Peek` 判断是否已锁定（不计数），仅密码校验失败时记录——
  成功登录不消耗配额，避免合法管理员频繁登录被误锁（`limiter.Peek` 与 `Allow` 分离）；
* 超限返回业务码 `A0241`（尝试超限），已锁定窗口内正确密码同样被拒；
* 限流 key 用 `c.ClientIP()`。单进程内存实现，多实例部署需迁移共享存储（同 ADR-0001 验证码的既有取舍）。

### 3. CORS 与 token 时效

* 后台引擎**不挂 CORS 中间件**——前端与后台同源嵌入（同一进程服务 `/admin`），无需跨域；
* `admin.expire_min` 默认 240 → 60 分钟，缩短管理端 token 暴露窗口。

### 4. 后台引擎的中间件取舍与文档适配

* 后台引擎**不挂 OperationLog**（`middleware/operationlog.go`）：后台流量是管理员自身
  的操作，不入面向客户端审计的 `operation_logs` 库，避免审计表被后台噪声淹没；
* 后台引擎**挂 Swagger 文档**（`registerSwagger`，`/api-docs`）：后台前端「API 文档」页
  以 iframe 内嵌 `/api-docs/index.html`，端口分离后需同端口可访问；后台默认仅
  `127.0.0.1` 监听，无公开风险。公开端口的文档由 `api_docs.enabled` 独立控制（默认关闭）。

## 被拒方案

* **防火墙/安全组白名单（仅此一项）**：依赖部署环境的网络配置，自托管用户易漏配，
  且无法覆盖同网段攻击；应用层限流仍是必要兜底。
* **后台继续同端口、仅加登录限流**：限流可防爆破，但 `/admin` 登录页与前端资源仍
  暴露公网（信息泄露 + 可被探测），网络隔离是第一道防线，成本低且彻底。

## 下游影响

* `main.go` 拆两个 Gin 引擎、两个 `http.Server`（后台 goroutine 启动）；
* `config.AdminConfig` 新增 `listen_addr` / `listen_port`（viper 默认 `127.0.0.1` / `9091`）；
* `internal/admin.Handler` 新增登录限流器；`Login` 超限返回 `A0241`（仅失败尝试计数）；
* `pkg/ratelimit.Limiter` 新增 `Peek`（只判断不记录），支持「先检查后记录」语义；
* 后台访问地址变化：`http://<host>:9090/admin` → `http://127.0.0.1:9091/admin`
  （`listen_addr` 可调）；
* `AGENTS.md` / `README.md` 配置说明同步。

## 验收

1. `go build ./...`、`go test -count=1 ./...` 全绿；
2. `0.0.0.0:9090` 上 `/admin*` 返回 404，公开 API 行为不变；
3. `127.0.0.1:9091` 后台可访问且独立鉴权；用局域网 IP 连 9091 连接失败；
4. 同一 IP 连续 6 次错误登录，第 6 次返回 `A0241`。
